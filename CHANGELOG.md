# Changelog

## 0.1.0 — 2026-11-14

- Introduce an original animated green holiday visitor with articulated limbs, blinking, a gift sack and three entrance styles.
- Add gift heists with approach, climb, reach, lift, stash and celebration phases.
- Add object-aware hiding, peeking, pointer reactions, tap-to-catch, animated returns and a kindness mode.
- Anchor gifts to document elements and support root clipping, nested scrolling and live layout changes.
- Provide a typed controller, events, live tuning, reduced-motion support, pause, SSR-safe imports and complete cleanup.
- Include a responsive playground, real runtime previews and framework integration examples.
